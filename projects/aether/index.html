Aether

Give your Mac a task in plain English and watch an AI drive the mouse and keyboard, live from your iPhone.

Working prototype

Illustration. Aether controls a real desktop, so the screens aren't shown here.

Overview

Chatbots can tell you how to do something. Aether is an experiment in what happens when an AI actually does it, using the same screen, mouse and keyboard you do.

It's a two-app system. Aether Agent lives in the Mac menu bar: it captures the screen, sends it to a vision-capable model, and carries out the planned steps as real mouse and keyboard events. Aether Mobile is the chat interface on the iPhone. It finds the Mac over Bonjour, pairs with a six-digit code, and streams live screenshots and step-by-step progress while the task runs. You might ask it to “open Chrome, look up vacation packages for these three weeks and summarize the best prices.”

A computer-use agent has to be safe as well as smart. Only one task can run at a time, enforced by a Swift actor. Every loop has a step cap and a kill switch on both devices, and any planned action containing a destructive verb pauses until you confirm it on the phone. The agent loop is provider-agnostic behind a small protocol and supports OpenAI and Anthropic vision models, with API keys kept in the macOS Keychain. Onboarding walks through the Accessibility, Screen Recording and Input Monitoring permissions with live status checks.

Key features

  • Natural-language tasks: describe the goal; the agent plans and acts
  • Real input: screen capture plus CGEvent mouse and keyboard control
  • Watch live: streamed screenshots and a step list on your iPhone
  • Pairing: Bonjour discovery and a six-digit code over a local WebSocket
  • Guardrails: single-task lock, step cap, kill switch, confirmation for risky actions
  • Bring your model: OpenAI or Anthropic vision models, keys in the Keychain
