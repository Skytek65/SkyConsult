AntiGravity Mobile

A native iPhone and iPad app for Google Antigravity. Start, steer and watch your AI coding agent from anywhere.

Working personal build · not on the App Store Built with Antigravity

Screens from the working app. Machine names and tunnel URLs are redacted.

Overview

Google Antigravity is a desktop agentic IDE. Its agents keep working long after you leave your desk, but there was no way to check on a task, answer the agent or start something new from your phone. Codex users get that mobile experience; Antigravity users don't.

AntiGravity Mobile fills that gap. It pairs a fully native SwiftUI app with a lightweight Node.js companion bridge that runs on the Mac. From the phone you can browse every Antigravity project, start a conversation with your choice of Gemini model, send follow-up prompts, and watch the agent think, run commands and edit files in real time.

Antigravity has no public API, so the interesting part is the bridge. It reads the agent's own on-disk state (project configs, its SQLite conversation store and its “brain” files) and drives the agent through its CLI and language-server entry points. A watcher tails those files and the SQLite write-ahead log, then fans changes out to the phone as live WebSocket deltas. For remote access the bridge opens a Cloudflare Tunnel. That makes the Mac reachable over HTTPS/WSS from cellular or behind CGNAT with no router setup, and pairing takes a one-second QR scan.

Key features

  • Live chat canvas: collapsible thinking, interactive tool-call cards (run_command, read_file, edit_file, search_web) with output and one-tap copy
  • Projects from your pocket: workspaces with git branch and chat counts; create or import projects from the phone
  • Model picker: start new chats on Gemini 3 Flash, Flash Lite or Pro
  • Artifacts drawer: plans, reports and diffs the agent produces, in a full-screen Markdown viewer
  • Slash commands: /plan, /goal, /learn, /compact, /browser and /boost with autocomplete
  • Connect anywhere: QR pairing, Bonjour LAN discovery, Cloudflare Tunnel, optional Cloudflare Access tokens
  • Native feel: haptics, glass materials, keyboard avoidance and an iPad split view
