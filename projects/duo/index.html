Duo

A native remote desktop for iPhone and iPad that speaks both VNC and Windows RDP.

In active development Built with Codex

Captured from the app with fictional computers and an offline sample desktop.

Overview

Getting to your Mac or PC from a phone usually means picking a protocol, fighting the touch controls and setting up connections that assume you're a network engineer. Duo is a remote desktop that feels like it belongs on iOS.

It's a native SwiftUI client that speaks both VNC and Microsoft's Remote Desktop Protocol, chosen per computer. You can keep up to eight sessions open across Macs and PCs and switch between them from a session rail. Each one can be driven with direct touch or a relative trackpad mode with dedicated click buttons. Duo finds nearby computers through Bonjour and a careful local scan. It connects over the LAN, Tailscale, an SSH tunnel or a self-hosted, end-to-end encrypted relay.

Under the hood, Duo implements the RFB protocol in Swift. It negotiates versions 3.3 to 3.8 with Hextile and CopyRect encodings, handles desktop resizing, and drops the color depth automatically when the link slows down. For RDP it embeds a FreeRDP and OpenSSL build with TLS 1.2+, NLA and pinned SHA-256 certificate fingerprints. Credentials stay in device-only Keychain storage. More than 70 XCTest unit and UI tests back it up, including real loopback VNC and TLS RDP rendering, along with Python integration tests for the relay and the file-transfer companion.

Key features

  • Two protocols: VNC (RFB 3.3–3.8) and native RDP, chosen per computer
  • Many sessions: up to eight open at once, mixed VNC and RDP
  • Real controls: direct touch, a relative trackpad mode, hardware keyboard and mouse
  • Find computers: Bonjour discovery plus a bounded, polite subnet scan
  • Secure routes: LAN, Tailscale, SSH tunnels, or your own end-to-end encrypted relay
  • Built for iOS: Face ID lock, iCloud-synced library, widgets, Siri Shortcuts, external displays
  • File transfer: through a companion HTTPS service and the Files app
